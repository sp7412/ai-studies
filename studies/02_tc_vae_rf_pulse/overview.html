Architecture

A variational autoencoder where each latent dimension has a physical name and is decoded by an architecture matched to its nature — not a flat isotropic Gaussian. The decoder losses are the forcing functions that carve each named slot into the shape you want.

Named latent slots

pulse_duration
Scalar — fraction of burst
mod_type
K-dim — Gumbel-softmax
mod_content
Vector — modulation depth
filter_shape
Vector — CVNN decoded
rise_time
Scalar — envelope onset
fall_time
Scalar — envelope decay
amplitude
Scalar — peak magnitude
residuals
Free dims — unstructured

Loss composition

ℒ_total = ℒ_recon + β·KL(q(z|x) ‖ p(z)) + α·Σ ℒ_param

ℒ_param includes:
  MSE(pred_amplitude, gt_amplitude) ← scalar slot
  MSE(pred_pulse_dur, gt_pulse_dur) ← scalar slot
  CrossEntropy(μ_mod_type, gt_class) ← discrete slot
  1 − CosSim(pred_mod_cont, target_mc) ← vector slot
  MSE(CVNN(z_filter), gt_sinc_filter) ← complex slot

Warmup schedule

Phase 1 — epochs 0–10Reconstruction only. Encoder learns the IQ manifold without any regularisation pressure.
Phase 2 — epochs 10–20β ramps 0 → 0.4. KL starts regularising posteriors toward Gaussian. Named slot shapes emerge.
Phase 3 — epochs 20–40α ramps 0 → 1. Auxiliary decoder losses engage, forcing named dims to align with physical params.
ThroughoutGumbel τ anneals 1.0 → 0.2, sharpening the mod_type discrete boundary progressively.

Bespoke decoders

CVNN — Trabelsi 2018

filter_shape decoder

Complex-valued linear layers using the Wirtinger formulation: W = W_r + j·W_i with separate float tensors. Enforces Hermitian symmetry on the decoded filter — the real filter's frequency response must be conjugate symmetric, and the CVNN respects this automatically. MSE loss against the windowed-sinc ground truth forces the slot to encode filter bandwidth.

Gumbel-softmax — Jang 2017

mod_type decoder

The modulation class (CW, LFM, BPSK, QPSK) is inherently discrete. The μ_mod_type logits are passed through a Gumbel-softmax relaxation during training so gradients flow through the discrete choice. Cross-entropy loss against the ground-truth class label forces the K-dim slot to become a clean one-hot classifier.

Scalar MLP

Scalar slots (pulse_dur, amplitude, rise, fall)

Two-layer MLP with sigmoid output constrains predictions to (0, 1). MSE loss against normalised ground-truth forces each slot to become a monotone linear encoding of the corresponding physical parameter. Cheap to train, robust — sigmoid prevents gradient explosions at init.

1D ConvTranspose

IQ reconstruction decoder

Takes z_concat (all named slots concatenated) through a projection MLP then a 5-layer 1D transposed convolution stack with stride-2 upsampling. Tanh output keeps IQ values in (−1, 1). The reconstruction MSE is the primary loss — it forces the encoder to use the full latent space, preventing posterior collapse.

Key takeaways

  • Warmup order determines what the encoder learns first Introducing auxiliary decoder losses too early prevents the encoder from learning a useful reconstruction manifold. The safe pattern: reconstruction only → KL warmup → auxiliary losses. Reversing this causes the encoder to overfit to parameter prediction and reconstruction never converges.
  • Per-slot KL beats aggregate KL with named latents If you sum all KL terms into one scalar and apply a single β, the model distributes KL budget unevenly — high-variance slots (mod_type) absorb most of the budget and squeeze out low-variance slots (rise_time). Per-slot free bits (Razavi 2019) prevent this.
  • CVNN improves filter_shape alignment over a real-valued MLP r² between z_filter and ground-truth filter_bw improves from ~0.61 (MLP) to ~0.79 (CVNN) because the complex multiplication rule enforces Hermitian symmetry — the constraint that a real filter's frequency response must satisfy.
  • Gumbel temperature annealing controls accuracy vs gradient flow High τ (≥ 1.0) gives smooth gradients but blurry class boundaries. Low τ (≤ 0.3) gives sharp boundaries but sparse gradients. Empirical sweet spot for mod_type accuracy is τ = 0.5 at eval time.
  • Latent traversal is the real sanity check — not correlation Scatter plots of μ vs ground-truth tell you correlation, but traversal tells you whether the decoder actually uses the named dim causally. A high r with a flat traversal means the label leaked via the task embedding — tighten task_emb_dim and re-examine.
